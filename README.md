> Это инструмент перехвата и фильтрации трафика, необходимый для работы zapret.
> Один и тот же инструмент могут применять как безопасные, так и вредоносные программы, однако сам WinDivert вирусом не является.
>
> **Фрагмент [`readme.md`](https://github.com/bol-van/zapret-win-bundle/blob/master/readme.md#%D0%B0%D0%BD%D1%82%D0%B8%D0%B2%D0%B8%D1%80%D1%83%D1%81%D1%8B) из репозитория [bol-van/zapret-win-bundle](https://github.com/bol-van/zapret-win-bundle)*
>
> Часть антивирусов классифицирует файлы WinDivert как потенциально опасные или относящиеся к хакерским инструментам. В таком случае файл удаляется и помещается в карантин. В названии обнаружения обычно присутствует `WinDivert` или `Not-a-virus:RiskTool.Multi.WinDivert`
>
> Добавьте каталог с запретом в исключения антивируса либо выключите обнаружение PUA (потенциально нежелательных приложений). Например, в Kaspersky есть параметр "Обнаруживать легальные приложения, которые злоумышленники часто используют для нанесения вреда". При уверенной настройке исключений лучше добавить исключение, но если вы не полностью понимаете последствия, рекомендуется отключить обнаружение PUA.

## ⚙️Установка и запуск

1. Активируйте безопасный DNS (Secure DNS)
    * В Chrome включите "Использовать безопасный DNS" и укажите поставщика, отличного от "Поставщика по умолчанию"
    * В Firefox откройте "DNS через HTTPS", выберите режим "Персональный", затем нажмите "Выбрать провайдера/поставщика" и вручную укажите URL. Например, `https://dns.google/dns-query` (поставщик Cloudflare может оказаться заблокирован)
    * Windows 11 позволяет включить Secure DNS непосредственно в настройках системы - [инструкция доступна здесь](https://remontka.pro/dns-over-https-windows-11/). Для Windows 11 этот вариант рекомендуется
    * При использовании роутера Keenetic включите в его настройках "Транзит запросов". Выключенная опция способна помешать настройке и работе Secure DNS на компьютере

2. Загрузите zip/rar-архив с [последнего релиза](https://github.com/Novanefunicular/zapret-discord-youtube/releases/latest)

3. Откройте свойства архива и установите флажок "Разблокировать". Для архивов, открытых через 7-Zip или PeaZip, этот шаг не требуется

4. Распакуйте архив в каталог, путь к которому не содержит кириллицу и специальные символы

5. Запустите подходящий файл
    * Для поиска рабочей стратегии откройте **`service.bat`** -> `Run Tests` -> `Standard tests` -> `All configs`
    * Чтобы включить автозапуск, выберите **`service.bat`** -> `Install Service` -> *подходящую стратегию*

## ℹ️Назначение файлов и пунктов

- [**`general.bat ...`**](./general.bat) - ручной запуск стратегии

  Такой запуск удобен для проверки разных стратегий. Результат зависит от множества условий, поэтому **перебирайте стратегии (ALT, FAKE и другие), пока не найдёте подходящую именно для вас**

- [**`service.bat`**](./service.bat) - установка автозапуска и дополнительные инструменты:
  - <ins>**`Install Service`** - добавление выбранной стратегии в автозапуск (services.msc)</ins>
  - **`Remove Services`** - удаление стратегии и WinDivert из служб
  - **`Check Status`** - просмотр состояния обхода и служб, включая автозапущенную стратегию и WinDivert
  - **`Game Filter`** - включение или выключение обхода для игр и других сервисов, использующих UDP и TCP на портах выше 1023.  
  **После изменения режима стратегию нужно перезапустить.**  
  Текущее состояние указано в скобках (включено/выключено).
  - **`IPSet Filter`** - переключение обхода для сервисов, перечисленных в `ipset-all.txt`.  
  Может пригодиться во время проверки ресурса, который без zapret открывается, а с ним работает некорректно.  
  В скобках отображается текущий режим:
    - `none` - ни один IP не участвует в проверке
    - `loaded` - IP проверяется по списку
    - `any` - под фильтр попадает любой IP  
  - **`Auto-Update Check`** - включение или отключение автоматической проверки обновлений
  - **`Replace active fakes`** - замена текущего фейка на другой файл из каталога `bin`
  - **`Update IPSet List`** - загрузка актуального `ipset-all.txt` из репозитория
  - **`Update Hosts File`** - обновление hosts <ins>**для восстановления веб-версии Telegram и подключения к голосовому чату Discord**</ins>
  - **`Check for Updates`** - ручная проверка наличия обновлений
  - **`Run Diagnostics`** - поиск распространённых причин, из-за которых zapret может не работать.  
  В завершение можно удалить кэш <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=11 /> `Discord`; это иногда помогает при внезапном сбое приложения
  - **`Run Tests`** - запуск проверки стратегий:
    - `Standard tests` - тестирование сайтов из `utils/targets.txt`
    - `DPI checkers` - проверка DPI у разных провайдеров, включая Cloudflare и Amazon


## ☑️Частые вопросы и неисправности

### После запуска `general*` не видно никаких изменений

- При запуске стратегии отдельным bat-файлом, а не через service, должен появиться winws.exe (обход), доступный в панели задач.  
Если этого не произошло, обратитесь к [#522](https://github.com/Novanefunicular/zapret-discord-youtube/issues/522)

### Ни одна стратегия не работает
- Откройте командную строку с правами администратора
- По очереди выполните команды:

    `netsh winsock reset`
  
    `netsh int ip reset all`
  
    `netsh winhttp reset proxy`
  
    `ipconfig /flushdns`

- Перезагрузите компьютер

### Не открывается Telegram в браузере
Запустите **`service.bat`** и нажмите **`Update hosts file`**. Если файл hosts окажется устаревшим, программа предложит обновить его вручную:  
  - Скопируйте весь текст из открывшегося Блокнота
  - Откройте файл `hosts` из появившегося каталога в текстовом редакторе, запущенном от имени администратора
  - Вставьте скопированный текст в конец `hosts` или замените ранее добавленные аналогичные строки
  - Сохраните файл и проверьте соединение. Если проблема осталась, убедитесь, что изменения действительно записались.

#### Работа не гарантирована. Если способ не помог, используйте [Desktop-версию](https://github.com/telegramdesktop/tdesktop/releases) с [локальным прокси](https://github.com/Novanefunicular/tg-ws-proxy) или любым публичным прокси.

### Обход не запускается или перестал помогать

> [!IMPORTANT]
> **Стратегии могут терять работоспособность со временем.**
> Стратегия способна работать некоторое время, а затем перестать из-за обнаружения.
> Здесь собрано много вариантов обхода. Если готовые варианты не подходят, создайте новую стратегию на основе одной из представленных и измените её параметры.
> Описание параметров стратегий находится [здесь](https://github.com/bol-van/zapret/blob/master/docs/readme.md#nfqws).

- В `service.bat` -> `Run Diagnostics` проверьте наличие ошибок

- Удостоверьтесь, что адрес нужного ресурса есть в списке доменов или IP-адресов

- Проверьте остальные стратегии, включая **`ALT`** и **`FAKE`**

- Выполните полную переустановку по инструкции ниже

- См. [#765](https://github.com/Novanefunicular/zapret-discord-youtube/issues/765)

### Как полностью обновить или переустановить проект?
- Сохраните добавленные вами ресурсы и данные
- Перезагрузите устройство
- Откройте `service.bat` -> `Remove Services`
- Запустите `service.bat` -> `Run Diagnostics`; при наличии ошибок исправьте их, затем в конце выберите Y
- Удалите каталог с запретом
- Загрузите свежую версию со [страницы релизов](https://github.com/Novanefunicular/zapret-discord-youtube/releases) (`zapret-discord-youtube-...`)
- Нажмите ПКМ по архиву и откройте свойства. Если внизу справа есть флажок разблокировки, установите его, нажмите "Применить" и "ОК"
- Распакуйте архив в новый каталог в корне диска; путь не должен содержать пробелы и специальные символы
- По очереди запускайте различные скрипты `general` и проверяйте интернет-ресурсы. Если доступ не работает, закройте программу через иконку замка в панели задач и выберите другую стратегию
- После выбора рабочей стратегии включите автозапуск через `service.bat` -> `Install Service` -> нужная стратегия

### Игра или приложение не работает при включённом запрете

- В `service.bat` проверьте, что `Game Filter` имеет состояние **`disabled`**, а `IPSet Filter` - **`none`**. Иначе фильтрация может затронуть неожиданные ресурсы.

### Античит обнаруживает WinDivert

- Ознакомьтесь с инструкцией: https://github.com/bol-van/zapret-win-bundle/tree/master/windivert-hide

### Windows 7 запрашивает цифровую подпись драйвера WinDivert

- В каталоге [`bin`](./bin) замените `WinDivert.dll` и `WinDivert64.sys` одноимёнными файлами из [zapret-win-bundle/win7](https://github.com/bol-van/zapret-win-bundle/tree/master/win7)

### После удаления через [**`service.bat`**](./service.bat) WinDivert всё ещё числится среди служб

1. Узнайте имя службы в командной строке Windows (Win+R, `cmd`):

```cmd
driverquery | find "Divert"
```

2. Остановите службу и удалите её следующими командами:

```cmd
sc stop название_из_первого_шага

sc delete название_из_первого_шага
```

### Не открывается <img src="https://cdn-icons-png.flaticon.com/128/1384/1384060.png" height=18 /> YouTube

- Проверьте, что настроен [Secure DNS](#%EF%B8%8Fустановка-и-запуск)
- Отключите блокировщик рекламы: известно, что YouTube начал с ними бороться.
- Переберите другие стратегии, особенно если раньше доступ работал.
- См. также [#251](https://github.com/Novanefunicular/zapret-discord-youtube/discussions/251)

### Не запускается <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=18 /> Discord

- Убедитесь, что включён [Secure DNS](#%EF%B8%8Fустановка-и-запуск)
- Сначала желательно определить стратегию, на которой открывается YouTube, и запустить её.
- В `service.bat` откройте `Run Diagnostics` и очистите там кэш Discord.
- Снова проверьте приложение Discord и результат очистки кэша.
- Откройте Discord в браузере: https://discord.com/app. Если веб-версия работает, можно пользоваться ей.
- Если Discord не работает и в браузере, повторно проверьте все стратегии: YouTube и Discord могут требовать разные варианты.
- См. также [#252](https://github.com/Novanefunicular/zapret-discord-youtube/discussions/252)

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968804.png" height=18 /> Telegram

- Попробуйте [tg-ws-proxy](https://github.com/Novanefunicular/tg-ws-proxy)
- Также можно использовать бесплатные MTProto-прокси из интернета

### Не работают игры

Игр много, поэтому проверить и исправить работу каждой отдельно невозможно.

Обычно помогает следующая последовательность:
- в `service.bat` обновите ipset и включите `Game Filter`
- если результата нет, дополнительно включите `ipset any`

Учтите: режим `ipset any` может нарушить открытие многих сайтов. Не оставляйте его включённым постоянно. Вместо этого определите IP-адреса, используемые игрой, и добавьте их в `ipset-all.txt`

Если проблема не решилась, создайте обсуждение в разделе [Discussions](https://github.com/Novanefunicular/zapret-discord-youtube/discussions), а не issue, и дождитесь помощи других игроков.

### Моей проблемы нет в списке

- Опишите её [здесь](https://github.com/Novanefunicular/zapret-discord-youtube/issues)

## 🗒️Добавление адресов других ресурсов

Списки обхода можно расширить вручную:
- домены добавляйте в **`list-general-user.txt`**; поддомены будут учтены автоматически
- домены-исключения указывайте в **`list-exclude-user.txt`**; это полезно, например, когда IP-сеть есть в `ipset-all.txt`, но отдельный домен фильтровать не нужно
- IP-адреса и подсети записывайте в **`ipset-all.txt`**
- исключения для IP-адресов и подсетей помещайте в **`ipset-exclude-user.txt`**
  - Файлы **`*-user.txt`** создаются автоматически при первом запуске `zapret` или `service.bat`
